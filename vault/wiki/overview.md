# Overview

Personal portfolio of Leow Kai Wen (fresh-graduate Full Stack Developer, Kuala Lumpur). Repo: `portfolio-website-ver-2.0`, branch `main`. Deployed on Vercel ([[deployment-vercel]]).

## Stack
Next.js 16.2.1 (Turbopack, App Router), React 19.2.4, TypeScript, Tailwind CSS 4, shadcn-style `ui/` components, GSAP, Lenis (smooth scroll), motion, three + @react-three/fiber + postprocessing + ogl (WebGL backgrounds), Vercel Analytics and Speed Insights. Fonts: Nunito Sans (Google) and Chroma Sans (local, `public/font`).
